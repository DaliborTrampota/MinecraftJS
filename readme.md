# Kroky

1. Nainstalovat Node.js verze 20.*
2. Otevřít 2x příkazový řádek v adresáři "voxel"
3. V jakémkoliv spustit příkaz "npm install"
4. V prvním spustit příkaz "npm run server" pro spuštění API serveru
5. Ve druhém spustit příkaz "npm run dev" pro spuštění webové stránky se hrou
6. Výstup druhého příkazu by mělo být pár řádku a jedním z nich s url adresou hry, většinou "http://localhost:5173/index.html"
